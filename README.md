# Interceptor Sandbox

Interceptor Sandbox is being redesigned as a local, standalone environment for
security testing deliberately onboarded agentic applications.

The product specifications live with the implementation in [`specs/`](specs/):

- [`specs/mvp.md`](specs/mvp.md) is the authoritative MVP specification.
- [`specs/decisions/0001-local-runtime-redesign.md`](specs/decisions/0001-local-runtime-redesign.md)
  records the architectural reorientation from the earlier distributed design.

No source code from the referenced implementation repository has been modified.
